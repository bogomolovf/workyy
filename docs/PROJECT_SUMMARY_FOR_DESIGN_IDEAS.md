# Сводка проекта Workyy — для генерации идей оформления (ChatGPT → Cursor)

Документ предназначен для отправки в ChatGPT, чтобы получить идеи по оформлению лендинга и всего продукта. Результат потом передаётся в Cursor для реализации.

---

## 1. Что такое Workyy

**Workyy** — браузерная платформа аналитики на бесконечном холсте (canvas). Это не классический BI и не просто ноутбук: объединяет возможности аналитических блокнотов (SQL, Python) с простотой BI-инструментов и совместной работой на одной доске.

**Ключевые месседжи:**

- «Business Analytics for Everyone» / «Бизнес-аналитика для всех»
- SQL, Python и визуализации на одной бесконечной доске
- No-Code и Pro-Code в одном месте
- Интерактивный canvas: перетаскивание, код, графики, стикеры, рисунки
- Реал-тайм коллаборация (курсоры, комментарии)
- Для аналитиков, продактов, инженеров аналитики, стартапов и малых команд

**Целевая аудитория:** аналитики данных, analytics engineers, продакт-менеджеры, основатели и команды; малый бизнес и стартапы, которым не подходят тяжёлые BI или изолированные ноутбуки.

## 2. Структура проекта (монорепо)

| Часть                    | Технологии                                             | Назначение                                      |
| ------------------------ | ------------------------------------------------------ | ----------------------------------------------- |
| **apps/landing**         | Vite, React 18, TypeScript, Tailwind CSS, React Router | Маркетинговый лендинг, онбординг                |
| **apps/web**             | Next.js, tldraw, React Flow, SQL/Python-узлы           | Основное приложение: доски, канва, визуализации |
| **apps/realtime-server** | Fastify, y-websocket                                   | Синхронизация и API                             |
| **packages/**            | core-domain, dag-executor, ui-kit, wasm-bridge         | Общие пакеты                                    |

Лендинг и продукт связаны: с лендинга ведут кнопки «Попробовать бесплатно» / «Войти» на `apps/web` (логин, доски).

## 3. Текущее оформление

### Лендинг (apps/landing)

- **Тема:** одна светлая тема «Workyy Blue».
- **Цвета:** белый фон, акцент `#2563eb` (синий), приглушённый текст `#64748b`, бордеры `#e0f2fe`. В CSS используются CSS-переменные (`--color-accent-primary`, `--color-text-primary` и т.д.) и Tailwind-классы `wy-primary`, `wy-text`, `wy-muted`, `wy-border`.
- **Фон главной:** белый + точечная сетка (dot grid), ассоциация с канвой/доской.
- **Типографика:** Inter, размеры от hero (clamp 2.5rem–4.2rem) до мелкого текста.
- **Компоненты:** карточки с тенями и hover, eyebrow-подзаголовки (uppercase, letter-spacing), кнопки primary/secondary/ghost, sticky header с blur.
- **Секции главной:** Hero → Trusted by (бегущая строка логотипов) → Продукт (Canvas, Collaboration, Performance) → Benefits (4 карточки) → Personas → Use Cases → Pricing (3 плана) → FAQ.
- **Языки:** EN и RU (переключатель в шапке), контент в `src/data/content.ts` и локально в страницах.
- **Страницы:** только Home (`/en/home`, `/ru/home`); в контенте упоминаются Product, Compare, Integrations, Pricing, Changelog, Roadmap — часть есть в данных, но в роутинге сейчас только Home (остальное можно вернуть или оформить заново).

**В текстах контента** есть отсылка к «Aurora»: «Design & User Experience – Aurora Inspired Interface», «Northern Lights Palette», «midnight blue», зелёные/бирюзовые акценты. В реальном UI сейчас реализована только синяя светлая тема, не тёмная «Aurora».

### Веб-приложение (apps/web)

- **Канва:** тёмная схема (`color-scheme: dark` в globals.css), стили для React Flow (курсоры, hand/select режимы), своя панель инструментов (`canvas.css` — светлые панели с blur, скругления).
- **Страницы:** главная, логин, регистрация, доска по id, демо-доска.
- **Визуал:** доска как бесконечный граф с узлами (SQL, Python, визуализации, документы и т.д.), коллаборативные курсоры.

Нужна согласованность визуального языка между лендингом и продуктом (цвета, шрифты, «ощущение» бренда).

## 4. Контент и навигация

- **Hero:** «Analytics Canvas», «SQL, Python, and visualizations on one infinite canvas», CTA «Start for free» / «See demo boards».
- **Тарифы:** Free, Pro ($49/мес), Enterprise (custom).
- **Use cases:** Data Analysis, Self-Serve Analytics, Reporting, Data Modeling, Product Analytics, Finance & Ops.
- **Интеграции:** Postgres, Snowflake, BigQuery, MySQL, CSV/файлы.
- **Сравнения:** Workyy vs Classic BI, vs Notebooks, для малых команд и стартапов.

Футер и контент отсылают к разделам: Product (Canvas, Collaboration, Performance, Pricing, Changelog, Roadmap), Use Cases, Compare, Integrations, Resources (Security, Privacy, Terms). Идеи оформления могут касаться и структуры лендинга (одна длинная главная vs отдельные страницы).

## 5. Что нужно от ChatGPT

Нужны **конкретные идеи по оформлению**, которые потом можно будет передать в Cursor и реализовать в коде:

1. **Лендинг**
   - Общая стилистика: минимализм, «data/tech», «Aurora» (тёмная/неон), корпоративный, стартап и т.д.
   - Цветовая палитра (с кодами цветов для светлой/тёмной темы при желании).
   - Типографика: шрифты для заголовков и тела текста.
   - Фон: оставить dot grid, градиент, иллюстрации, видео, 3D?
   - Hero: композиция, акцент на иллюстрации/скриншоте продукта/тексте.
   - Карточки, кнопки, отступы: стиль (скругления, тени, границы).
   - Секция «Trusted by»: как лучше подать (marquee, статичная сетка, другой формат).
   - Анимации: лёгкие появления, микро-интеракции — да/нет и в каком объёме.

2. **Единый стиль продукта**
   - Как связать визуал лендинга и приложения (общая палитра, один дизайн-токен-набор).
   - Нужна ли тёмная тема на лендинге (например, вариант «Aurora») и как её переключать с продуктом.
   - Header/Footer: стиль, плотность информации, CTA.

3. **Технические огранижения для идей**
   - Лендинг: React + Tailwind, CSS-переменные, без жёсткой привязки к конкретной UI-библиотеке.
   - Продукт: Next.js, уже есть тёмная канва и свои компоненты — идеи должны быть применимы без полной переписи (цвета, шрифты, токены).

4. **Формат ответа для Cursor**
   - Краткое описание стилистики (1–2 абзаца).
   - Палитра: названия ролей (primary, background, text, muted, border) + hex/rgb.
   - Шрифты: названия и где применять (hero, body, UI).
   - Конкретные предложения по секциям (Hero, карточки, Trusted by, Pricing, Footer).
   - Опционально: идеи по иллюстрациям, иконкам, логотипу.

## 6. Как использовать этот документ

1. Скопировать весь текст (или нужные разделы) и вставить в ChatGPT.
2. Дополнить запрос, например: «Дай идеи оформления лендинга и продукта по этой сводке. Результат оформь так, чтобы я мог отдать его разработчику в Cursor для реализации в коде (цвета в hex, шрифты, конкретные предложения по секциям).»
3. Ответ ChatGPT сохранить и отправить в Cursor с просьбой реализовать оформление в проекте (лендинг в apps/landing, при необходимости — глобальные стили и токены в apps/web).
