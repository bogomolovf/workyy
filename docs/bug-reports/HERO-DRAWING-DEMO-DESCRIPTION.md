# Описание задачи / возможного дефекта: Hero Drawing Demo

## Важное уточнение

В истории чата **не было явного сообщения о баге** (что-то сломалось и не починилось). Описаны **доработки лендинга**: анимации превью виджетов (Рисование, Голосовые, Загрузка файлов, AI) и требование, чтобы они **соответствовали поведению на доске**. Ниже — структурированное описание задачи, реализованного решения и возможных расхождений для последующей обработки (в т.ч. командой `fix-bug`).

---

## Краткое резюме

Требовалось, чтобы анимация рисования в Hero-превью лендинга показывала название проекта «Workyy» **стандартным шрифтом**, рисование **как по доске** (пером) и стирание **ластиком**, в соответствии с тем, **как это устроено на самой доске**. Текущая реализация использует текст + `clip-path` (появление/исчезновение слева направо), что лишь имитирует рисование и стирание; на доске рисование — это свободные штрихи (PenNode), а стирание — удаление узлов пера при пересечении с треком ластика.

---

## Исходные требования (из чата)

**Что просили:**

1. **Рисование**
   - Надпись «Workyy» (название проекта).
   - Буквы в **стандартном шрифте**.
   - Анимация **как будто рисуется по доске** (пером).
   - Затем анимация **как будто стирается ластиком**.
   - Всё должно быть **взято с того, как организовано на самой доске**.

2. **Голосовые**
   - Показывать **процесс записи** (не воспроизведение).

3. **Загрузка файлов**
   - Загрузка **презентации** и её открытие **как книжка**, листание слайдов.
   - Контент: презентация про **китов в Северном Ледовитом океане**.

---

## Дефектное / нежелательное поведение (потенциальное)

**Что может быть не так:**

- Демо рисования **не повторяет механику доски**: на доске рисование — это свободные пути (perfect-freehand → path), а стирание — пересечение трека ластика с узлами пера и их удаление. В Hero используется только текст + две анимации `clip-path` (появление и исчезновение слева направо), без реальных штрихов и без логики «ластик проводит по контенту».
- Если ожидалось **визуальное и поведенческое соответствие** доске (штрих за штрихом, ластик «ведётся» по области), текущая реализация даёт только **метафору** рисования/стирания, а не ту же модель, что в продукте.

**Ожидаемое поведение (интерпретация):**

- Надпись «Workyy» в стандартном шрифте.
- Визуально и по ощущению — «рисуется по доске» и «стирается ластиком», в духе того, как устроены перо и ластик на доске.

**Фактическое поведение:**

- Текст «Workyy» в system-ui/sans-serif.
- «Рисование» — раскрытие текста слева направо через `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)`.
- «Стирание» — сокрытие слева направо через `inset(0 0 0 0)` → `inset(0 0 0 100%)`.
- Нет реальных штрихов пера и нет движения «ластика» по контуру.

## Воспроизведение

**Шаги:**

1. Открыть лендинг (например, `apps/landing`, маршрут с Hero).
2. В Hero-превью кликнуть по карточке «Рисование» (или эквивалент).
3. Дождаться цикла: появление надписи «Workyy» → пауза → исчезновение.

**Условия:**

- Окружение: dev (лендинг).
- Предварительные условия: без `prefers-reduced-motion: reduce` (иначе анимации отключены).

## Корневая причина (гипотезы)

1. **Разные цели**  
   На доске — реальные данные (points, узлы, пересечения); на лендинге нужна короткая, стабильная анимация без тяжёлой логики. Поэтому выбрана имитация через clip-path, а не полная механика пера/ластика.

2. **Неоднозначность формулировки**  
   «Как организовано на самой доске» можно понимать как (a) визуальное сходство и ощущение «рисуют/стирают» или (b) буквально ту же модель (штрихи, ластик по области). Реализация следует (a).

3. **Ограничения лендинга**  
   Полноценное повторение механики (perfect-freehand, проверка пересечений) на лендинге потребовало бы либо пререндеренной анимации (например, Lottie), либо упрощённой модели «штрихов» и «ластика» поверх текста/path.

## Рекомендации для исправления / доработки

**Если нужно усилить соответствие доске:**

1. **Вариант A (минимальный):**  
   Оставить текст + clip-path, но добавить визуал «ластика» (полоса или круг, движущийся слева направо во время фазы стирания), чтобы ощущение «водят ластиком» было явнее.

2. **Вариант B (средний):**  
   Вернуться к SVG path для «Workyy» (шрифт конвертировать в path, чтобы буквы были в стандартном начертании), рисование — `stroke-dashoffset`, стирание — обратная анимация или маска, движущаяся по path (как ластик по контуру).

3. **Вариант C (максимальный):**  
   Упрощённая модель «доски»: несколько заранее заданных stroke-path’ов (имитация штрихов пера), поочерёдное появление; стирание — маска или исчезновение по пути ластика (например, gradient mask, движущийся вдоль path).

**Важно:**

- Сохранять учёт `prefers-reduced-motion` (как сейчас).
- Не тянуть в лендинг тяжёлые зависимости продукта (perfect-freehand, полный EraserOverlay).
- Проверить цикл таймеров и cleanup (requestAnimationFrame, setTimeout) при размонтировании — текущая реализация уже отменяет их в useEffect cleanup.
