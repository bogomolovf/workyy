# Архитектура Workyy

Эта директория содержит архитектурную документацию проекта.

## Структура

- `adr/` — Архитектурные решения (Architecture Decision Records)
- `diagrams/` — Диаграммы (ERD, sequence diagrams)
- `runtime/` — Документация по запуску сервисов

## Основные документы

- [ADR 0001: Bootstrap Stack](./adr/0001-bootstrap.md) - Выбор технологического стека
- [ERD Diagram](./diagrams/erd.md) - Схема базы данных

## Добавление новой документации

При принятии важных архитектурных решений создавайте ADR:

1. Создайте файл `adr/NNNN-<краткое-название>.md`
2. Следуйте формату существующих ADR
3. Обновите этот README с ссылкой на новый ADR
