# Мета-промпт для ChatGPT: сгенерировать промпт для Cursor AI (улучшение Task Tracker)

Скопируй блок ниже **целиком** в ChatGPT. Попроси ответ **на русском** или **на английском** — как удобнее для передачи в Cursor.

---

## Текст для ChatGPT

Ты — продуктовый техлид и UX-редактор. Твоя задача: **написать один готовый промпт для ИИ-разработчика в Cursor**, чтобы он **улучшил уже существующий** в продукте **Task Tracker** (YouGile-подобный: kanban, задачи, колонки, деталка, комментарии, метки, подзадачи), **не переписывая всё с нуля** и **не смешивая с canvas-board**.

### Контекст (зафиксируй в промпте)

- В репозитории уже есть MVP: отдельная сущность `TaskTracker` (не `Board`), Prisma-модели, API под `/api/trackers/...`, фронт `apps/web` — роут `/tracker/[trackerId]`, вкладки Boards | Trackers на главной, `@dnd-kit`, `trackerApi.ts`, `trackerSettingsStore`, переводы в `translations.ts`.
- Стек: monorepo, Next.js в `apps/web`, Fastify + Prisma в `apps/realtime-server`, контракты в `docs/api/openapi.yaml`.
- Улучшения должны опираться на **текущий код и паттерны**, а не на выдуманные пути файлов — в промпте попроси Cursor **сначала прочитать** актуальные файлы и только потом менять.

### Что должен сделать итоговый промпт для Cursor

1. **Цель улучшения** — сформулировать 3–7 конкретных направлений на выбор (пользователь может дополнить списком):
   - UX: мобильная деталка (full-screen), side panel на desktop, пустые состояния, доступность.
   - Kanban: стабильный DnD (порядок в колонке, между колонками), reorder колонок, edge cases.
   - Данные: согласованность `position`/`completedAt`, удаление колонок, миграции только при необходимости.
   - Синхронизация: polling vs realtime — явно пометить trade-off.
   - Поиск/recents: расширить существующий sidebar/home, если инфраструктура позволяет; иначе — минимальный follow-up.
   - Качество: тесты на критичные хелперы/валидаторы, линтер, OpenAPI в актуальном виде.
2. **Границы**: что **не** трогать без запроса (canvas board, Yjs для досок, крупный редизайн всего приложения).
3. **Формат работы**: короткий аудит → список изменений по слоям → минимальный diff → чеклист проверки.
4. **Assumptions**: всё спорное — «уточнить у команды».

### Формат ответа ChatGPT

- Один **цельный промпт** для Cursor, вставляемый в чат агента **как есть**.
- В конце — **5–10 открытых вопросов** к команде (приоритеты, продуктовые ограничения).

### Стиль

- Конкретно, без воды.
- Не выдумывать новые endpoint-имена — «расширять по аналогии с `trackers.ts` / `trackerApi.ts`».

## Как использовать

1. Вставь ответ ChatGPT в новый чат **Cursor Agent**.
2. Добавь одну строку: «Репозиторий: Workyy; улучшай только task tracker; начни с чтения `apps/realtime-server/src/routes/trackers.ts`, `apps/web/src/app/tracker/`, `apps/web/src/components/tracker/`, `prisma/schema.prisma` для Task\*.»
3. Если нужно сузить scope — перечисли 2–3 пункта из сгенерированного списка направлений.
