# Быстрый старт с Cursor AI

## ⚡ 5-минутная настройка

### 1. Установи Cursor

- Скачай с [cursor.com](https://cursor.com)
- Установи и запусти
- Проверь обновления: `Help → Check for Updates`

### 2. Открой проект

```bash
cd workyy-fullproject-stable
cursor .
```

### 3. Готово!

Cursor автоматически прочитает `.cursorrules` и начнет работать с правилами проекта.

## 🎯 Первая задача

### Изучение проекта

Открой Cursor Ask и спроси:

```
"Объясни архитектуру проекта Workyy"
"Покажи примеры паттернов кода"
"Как работает синхронизация канвы?"
```

### Разработка фичи

1. Создай ветку: `git checkout -b feature/my-task`
2. Открой Cursor Agent (`Ctrl+I`)
3. Скажи:

```
/develop-feature

Название фичи: [НАЗВАНИЕ]
Контекст задачи: [ОПИСАНИЕ]
Требования: [СПИСОК]
```

### Проверка перед PR

```
/review-pr для проверки моих изменений
```

## 📚 Основные команды

- `/review-pr` - Проверка PR
- `/create-test` - Создание тестов
- `/check-architecture` - Проверка архитектуры
- `/resolve-conflict` - Разрешение конфликтов

## 🤖 Специализированные агенты

### Code Reviewer

```
/code-reviewer

Проверь мои изменения
```

Или используй команду:

```
/code-review

Ветка: [ВЕТКА]
Проверь следующее: [СПИСОК]
```

### Test Generator

```
/test-generator

Создай тесты для [файл]
```

Или используй команду:

```
/create-test
```
