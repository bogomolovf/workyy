# Cursor AI Configuration для Workyy

Этот каталог содержит всю конфигурацию для эффективной работы команды с Cursor AI.

## 📁 Структура

```
.cursor/
├── README.md              # Этот файл
├── TEAM_WORKFLOW.md       # Полное руководство по командной работе
├── tasks.md               # Трекинг задач команды
├── knowledge/             # База знаний проекта
│   ├── architecture.md    # Архитектура системы
│   ├── patterns.md        # Паттерны кода
│   ├── decisions.md       # Архитектурные решения (ADR)
│   └── onboarding.md     # Онбординг новых разработчиков
├── prompts/               # Хранилище хороших промптов (команда добавляет сюда полезные промпты)
├── commands/              # Команды Cursor
│   ├── agents/            # Агентские команды (активируют специализированных агентов)
│   │   ├── developer.md        # ⭐ Универсальный агент-разработчик
│   │   ├── code-reviewer.md
│   │   ├── test-generator.md
│   │   └── migration-helper.md
│   └── tasks/             # Команды задач (выполняют конкретные задачи)
│       ├── fix-bug.md          # ⭐ Исправление багов
│       ├── develop-feature.md  # ⭐ Разработка новых фич
│       ├── refactor.md         # ⭐ Рефакторинг кода
│       ├── code-review.md      # ⭐ Код-ревью
│       ├── review-pr.md
│       ├── create-test.md
│       └── ... (14 команд всего)
```

## 🚀 Быстрый старт

### 1. Для новых разработчиков

1. Прочитай `.cursorrules` в корне проекта
2. Изучи `.cursor/knowledge/onboarding.md`
3. Прочитай `.cursor/TEAM_WORKFLOW.md`
4. Изучи команды из `.cursor/commands/README.md`

### 2. Для ежедневной работы

1. Используй команды из `.cursor/commands/` (через префикс `/` в чате)
2. Активируй специализированных агентов через `/developer`, `/code-reviewer`, `/test-generator`, `/migration-helper`
3. Используй команды задач: `/fix-bug`, `/develop-feature`, `/refactor`, `/code-review` и другие
4. Обновляй `.cursor/tasks.md` для трекинга задач
5. Экспортируй важные чаты в `.cursor/knowledge/`

## 📚 База знаний

**Когда использовать:**

## 🎯 Команды Cursor

### Готовые команды (`.cursor/commands/`)

Все команды уже настроены и доступны через префикс `/` в чате Cursor:

**Основные команды:**

- `/fix-bug` ⭐ - Исправление багов
- `/develop-feature` ⭐ - Разработка новых фич
- `/refactor` ⭐ - Рефакторинг кода
- `/code-review` ⭐ - Код-ревью

**Дополнительные команды:**

- `/review-pr` - Проверка Pull Request
- `/create-test` - Создание тестов
- `/check-architecture` - Проверка архитектуры
- `/check-security` - Проверка безопасности
- `/analyze-performance` - Анализ производительности
- `/resolve-conflict` - Разрешение конфликтов
- `/prepare-prod` - Подготовка к продакшну
- `/create-docs` - Создание документации
- `/suggest-improvements` - Предложения по улучшению
- `/explain-code` - Объяснение кода

**Агентские команды:**

- `/developer` ⭐ - Универсальный агент-разработчик
- `/code-reviewer` - Агент для код-ревью
- `/test-generator` - Агент для создания тестов
- `/migration-helper` - Агент для работы с миграциями

**Использование:**

```
/review-pr

/create-test
```

**Проверка загрузки:**

- Settings → Rules and Commands → "Import Claude Commands" должно быть включено
- Команды появятся в разделе "Project Commands"

## 🤖 Специализированные агенты

Агенты активируются через команды в чате Cursor:

### `/code-reviewer`

Активирует Code Reviewer Agent для проведения код-ревью.

**Использование:**

```
/code-reviewer

Проверь мои изменения:
- Особое внимание на безопасность
- Проверь производительность
```

Или используй команды задач после активации:

```
/code-reviewer
/review-pr
/check-security
```

### `/test-generator`

Активирует Test Generator Agent для создания тестов.

**Использование:**

```
/test-generator

Создай тесты для [файл]:
- Покрой все сценарии
- Включи edge cases
```

Или используй команду:

```
/test-generator
/create-test
```

### `/migration-helper`

Активирует Migration Helper Agent для работы с миграциями БД.

**Использование:**

```
/migration-helper

Проверь миграцию [название]:
- Безопасность
- Обратная совместимость
```

### `/developer` ⭐

Универсальный агент-разработчик для любых задач разработки.

**Использование:**

```
/developer

Создай компонент BoardList:
- Показывает все доски пользователя
- Поддерживает поиск и фильтрацию
```

**Подробнее:** См. `.cursor/commands/README.md` для полного описания агентов.

## 🔄 Обновление базы знаний

### Когда обновлять

1. **После важных решений**
   - Обновляй `decisions.md`
   - Добавляй новые ADR

2. **После изучения кода**
   - Экспортируй важные чаты
   - Добавляй в соответствующие файлы

3. **После создания новых паттернов**
   - Обновляй `patterns.md`
   - Добавляй примеры

4. **После изменений архитектуры**
   - Обновляй `architecture.md`
   - Обновляй `decisions.md`

### Как обновлять

1. **Экспорт чатов из Cursor**
   - Кнопка экспорта в чате
   - Сохраняй в `.cursor/knowledge/`

2. **Ручное обновление**
   - Редактируй файлы напрямую
   - Следуй существующему формату

3. **Используй Cursor для помощи**
   ```
   "Обнови .cursor/knowledge/architecture.md с информацией о [изменение]"
   ```
