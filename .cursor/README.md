# Cursor AI Configuration

Эта директория содержит конфигурацию для Cursor AI в проекте Workyy.

## Структура

```
.cursor/
├── README.md           # Этот файл
├── knowledge/          # База знаний проекта (архитектура, паттерны, решения)
├── prompts/            # Хранилище полезных промптов (команда добавляет сюда)
└── commands/           # Пользовательские команды Cursor
    ├── agents/         # Команды-агенты (активируют специализированных агентов)
    └── tasks/          # Команды задач (выполняют конкретные задачи)
```

## Как использовать

### База знаний (knowledge/)

Файлы в `knowledge/` автоматически читаются Cursor и используются для контекста при работе с проектом.

Добавляйте сюда важную информацию:

- Архитектурные решения
- Паттерны кода
- Принятые решения
- Onboarding информацию

### Промпты (prompts/)

Сохраняйте полезные промпты, которые хорошо работают. Команда может делиться эффективными промптами через эту директорию.

### Команды (commands/)

Добавляйте пользовательские команды Cursor в подпапки:

- **`commands/agents/`** - команды-агенты (например, `/developer`, `/code-reviewer`)
- **`commands/tasks/`** - команды задач (например, `/fix-bug`, `/develop-feature`)

#### Формат команды

Создайте `.md` файл с именем команды. Например, `commands/agents/developer.md`:

```markdown
# Developer Agent

Описание агента.

## Prompt

Ты Developer Agent для проекта Workyy.
[Инструкции для агента]
```

После создания команды она автоматически станет доступна через префикс `/` в чате Cursor (если включен "Import Claude Commands" в настройках).

## Настройка Cursor

1. Открой Settings: `Cmd+,` (Mac) или `Ctrl+,` (Windows/Linux)
2. Перейди в "Rules and Commands"
3. Включи "Import Claude Commands" (зеленый переключатель)
4. Перезагрузи окно: `Cmd+Shift+P` → "Reload Window"

Команды автоматически загружаются из этой директории.

## Правила проекта

Основные правила проекта находятся в `.cursorrules` в корне проекта.
