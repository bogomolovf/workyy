# Suggest Improvements

Предложение улучшений для кода: рефакторинг, оптимизация, улучшение читаемости.

## Prompt

Проанализируй код и предложи улучшения: рефакторинг, оптимизация, улучшение читаемости.

**КРИТИЧЕСКИ ВАЖНО:**

- Сохрани ВСЕ детали задачи пользователя - не теряй контекст
- Работай автономно до полного завершения анализа
- Используй codebase_search для изучения паттернов и best practices
- Выполняй множественные поиски для полного понимания

## Процесс анализа

### Шаг 1: Понимание контекста

**Сохрани ВСЕ детали:**

- Какие файлы/компоненты нужно проанализировать
- На что обратить особое внимание
- Какие аспекты критичны (читаемость, производительность, архитектура)
- Любые специфические требования

### Шаг 2: Изучение паттернов и best practices

**Используй codebase_search для изучения:**

- Какие паттерны используются в проекте
- Какие best practices применяются
- Примеры хорошо написанного кода
- Как решаются похожие задачи

**Примеры поисков:**

```
codebase_search: "What patterns are used for similar functionality?"
codebase_search: "How is error handling implemented in this project?"
codebase_search: "What are the best practices for React components?"
codebase_search: "How is code refactored in this codebase?"
```

**Выполняй множественные поиски параллельно** для максимальной эффективности.

### Шаг 3: Анализ кода

**Читаемость:**

- Понятность названий переменных и функций
- Структура кода
- Комментарии где нужно
- Размер функций (не слишком большие)
- Избегание глубокой вложенности

**Производительность:**

- Оптимизация алгоритмов
- Мемоизация где нужно (React)
- Ленивая загрузка
- Оптимизация запросов к БД
- Избегание лишних вычислений

**Архитектура:**

- Следование SOLID принципам
- Разделение ответственности
- Переиспользование кода
- Использование правильных паттернов
- Использование существующих пакетов

**Best Practices:**

- TypeScript best practices
- React best practices (если frontend)
- Node.js/Fastify best practices (если backend)
- Следование .cursorrules
- Следование паттернам из .cursor/knowledge/patterns.md

**Рефакторинг:**

- Упрощение сложного кода
- Удаление дублирования
- Вынесение общих частей
- Улучшение структуры
- Разбиение больших функций/компонентов

### Шаг 4: Форматирование ответа

**Структурируй ответ по категориям:**

1. **Критические улучшения (нужно исправить)**
   - Проблемы которые важно исправить
   - Указывай конкретные файлы и строки: `filepath:line_number`
   - Объясняй почему это важно
   - Предлагай конкретные решения

2. **Важные улучшения (рекомендуется)**
   - Улучшения которые желательны
   - Указывай конкретные места: `filepath:line_number`
   - Объясняй преимущества
   - Предлагай конкретные улучшения

3. **Мелкие улучшения (можно улучшить)**
   - Улучшения которые не критичны но полезны
   - Объясняй преимущества
   - Предлагай конкретные улучшения

**Для каждого улучшения указывай:**

- Место в коде: `filepath:line_number`
- Приоритет: high/medium/low
- Объяснение почему это улучшение
- Примеры как можно улучшить
- Связь с паттернами проекта если есть

## Готов к работе

Проанализируй код и предложи улучшения. Я:

1. Сохраню ВСЕ детали твоей задачи
2. Изучу паттерны и best practices через codebase_search
3. Проведу полный анализ кода
4. Предоставлю структурированный список улучшений с приоритетами
5. Завершу работу только когда анализ полностью завершен
