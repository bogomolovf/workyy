# Analyze Performance

Анализ производительности кода с выявлением проблем и предложением оптимизаций.

## Prompt

Проанализируй производительность кода и найди возможности для оптимизации.

**КРИТИЧЕСКИ ВАЖНО:**

- Сохрани ВСЕ детали задачи пользователя - не теряй контекст
- Работай автономно до полного завершения анализа
- Используй codebase_search для изучения паттернов оптимизации
- Выполняй множественные поиски для полного понимания

## Процесс анализа

### Шаг 1: Понимание контекста

**Сохрани ВСЕ детали:**

- Какие файлы/компоненты нужно проанализировать
- На что обратить особое внимание
- Какие аспекты производительности критичны
- Любые специфические требования

### Шаг 2: Изучение паттернов оптимизации

**Используй codebase_search для изучения:**

- Как оптимизированы запросы к БД
- Как используется мемоизация в React
- Какие паттерны оптимизации уже используются
- Примеры оптимизированного кода

**Примеры поисков:**

```
codebase_search: "How are Prisma queries optimized in this project?"
codebase_search: "How is React memoization used in components?"
codebase_search: "What patterns are used for code splitting?"
codebase_search: "How is lazy loading implemented?"
```

**Выполняй множественные поиски параллельно** для максимальной эффективности.

### Шаг 3: Детальный анализ

**Backend (apps/realtime-server):**

**База данных:**

- ✅ Нет N+1 запросов к БД
- ✅ Используется select в Prisma (не загружаем лишние данные)
- ✅ Правильное использование индексов
- ✅ Оптимизация запросов (JOIN вместо множественных запросов)
- ✅ Кэширование где нужно
- ✅ Пагинация для больших списков

**API:**

- ✅ Оптимизация обработки запросов
- ✅ Правильная обработка асинхронных операций
- ✅ Нет блокирующих операций
- ✅ Правильное использование пулов соединений

**Frontend (apps/web):**

**React оптимизация:**

- ✅ Мемоизация компонентов (React.memo)
- ✅ Мемоизация вычислений (useMemo)
- ✅ Мемоизация колбэков (useCallback)
- ✅ Правильное использование зависимостей в хуках
- ✅ Оптимизация ре-рендеров
- ✅ Избегание лишних ре-рендеров

**Загрузка:**

- ✅ Ленивая загрузка компонентов (lazy loading)
- ✅ Размер бандла (code splitting)
- ✅ Оптимизация изображений
- ✅ Правильное использование динамических импортов

**Общее:**

- ✅ Нет лишних вычислений в циклах
- ✅ Эффективное использование памяти
- ✅ Оптимизация алгоритмов
- ✅ Избегание создания лишних объектов/массивов

### Шаг 4: Форматирование ответа

**Структурируй ответ:**

1. **Критические проблемы (high priority)**
   - Проблемы которые сильно влияют на производительность
   - Указывай конкретные файлы и строки: `filepath:line_number`
   - Оценка влияния на производительность
   - Конкретные предложения по оптимизации

2. **Важные проблемы (medium priority)**
   - Проблемы которые заметно влияют на производительность
   - Указывай конкретные места: `filepath:line_number`
   - Оценка влияния
   - Предложения по оптимизации

3. **Рекомендации (low priority)**
   - Улучшения которые могут помочь
   - Объясняй преимущества
   - Предлагай конкретные оптимизации

**Для каждой проблемы указывай:**

- Место в коде: `filepath:line_number`
- Оценка влияния: high/medium/low
- Конкретное предложение по оптимизации
- Пример кода если нужно

## Готов к работе

Проанализируй производительность кода. Я:

1. Сохраню ВСЕ детали твоей задачи
2. Изучу паттерны оптимизации через codebase_search
3. Проведу полный анализ производительности
4. Предоставлю структурированный отчет с приоритетами
5. Завершу работу только когда анализ полностью завершен
