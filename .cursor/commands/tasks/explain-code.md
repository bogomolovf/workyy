# Explain Code

Детальное объяснение как работает код: логика, поток выполнения, зависимости.

## Prompt

Объясни как работает этот код: логика, поток выполнения, зависимости и связи с проектом.

**КРИТИЧЕСКИ ВАЖНО:**

- Сохрани ВСЕ детали задачи пользователя - не теряй контекст
- Работай автономно до полного завершения объяснения
- Используй codebase_search для понимания контекста и зависимостей
- Выполняй множественные поиски для полного понимания

## Процесс объяснения

### Шаг 1: Понимание задачи

**Сохрани ВСЕ детали:**

- Какой код нужно объяснить
- На каком уровне детализации (высокий/низкий)
- Какие аспекты важны (логика, производительность, безопасность)
- Любые специфические вопросы

### Шаг 2: Изучение контекста

**Используй codebase_search для изучения:**

- Как используется этот код
- От каких компонентов зависит
- Какие компоненты зависят от этого кода
- Как вписывается в архитектуру
- Связи с другими частями проекта

**Примеры поисков:**

```
codebase_search: "How is this code used in the codebase?"
codebase_search: "What are the dependencies of this code?"
codebase_search: "How does this relate to other components?"
codebase_search: "What patterns are used in similar code?"
```

**Выполняй множественные поиски параллельно** для максимальной эффективности.

### Шаг 3: Детальное объяснение

**Логика:**

- Что делает код
- Как работает алгоритм
- Какие данные обрабатывает
- Какие результаты возвращает
- Какие побочные эффекты

**Поток выполнения:**

- Пошаговое выполнение
- Условия и ветвления
- Циклы и итерации
- Асинхронные операции
- Обработка ошибок

**Зависимости:**

- Какие модули/пакеты использует
- От каких компонентов зависит
- Какие компоненты зависят от этого кода
- Связи с другими частями проекта
- Импорты и экспорты

**Контекст проекта:**

- Где используется этот код
- Как вписывается в архитектуру
- Связь с другими компонентами
- Роль в общей системе
- Следование паттернам проекта

**Потенциальные проблемы:**

- Edge cases которые могут не обрабатываться
- Потенциальные баги
- Проблемы производительности
- Проблемы безопасности
- Улучшения которые можно сделать

**Примеры:**

- Примеры использования
- Примеры входных/выходных данных
- Типичные сценарии
- Edge cases

### Шаг 4: Форматирование объяснения

**Структура:**

1. **Общее описание** - что делает код в целом
2. **Детальное объяснение** - как работает пошагово
3. **Зависимости и связи** - как связано с проектом
4. **Потенциальные проблемы** - что нужно учесть
5. **Примеры** - как использовать

**Используй:**

- Ссылки на код: `filepath:line_number`
- Примеры кода с объяснениями
- Диаграммы потока если нужно
- Связи с другими компонентами

## Готов к работе

Объясни как работает код. Я:

1. Сохраню ВСЕ детали твоей задачи
2. Изучу контекст и зависимости через codebase_search
3. Предоставлю детальное объяснение всех аспектов
4. Покажу связи с проектом
5. Завершу работу только когда объяснение полностью готово
