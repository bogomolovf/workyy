```markdown

**Описание**: [Детальное описание]
**Ответственный**: [Имя]
**Приоритет**: [High/Medium/Low]
**Статус**: [In Progress/In Review/Blocked]

**Заметки**: [любые заметки]
```

## 🔄 Как использовать

1. **При начале работы над задачей**
   - Добавь в "В работе"
   - Укажи ответственного
   - Обнови статус

2. **При создании PR**
   - Перемести в "В ревью"
   - Укажи номер PR
   - Укажи ревьюера

3. **После завершения**
   - Перемести в "Завершенные"
   - Добавь комментарий о результате

## 💡 Советы

- Обновляй статусы регулярно
- Используй GitHub Issues для детального трекинга
- Синхронизируйся с командой на ежедневных стендапах
- Используй Cursor для автоматизации обновлений:
  ```
  "Обнови .cursor/tasks.md: перемести задачу #123 в 'В ревью'"
  ```
