# Архитектура Workyy

## Обзор системы

Workyy — браузерная платформа аналитики на бесконечном холсте. Система позволяет создавать пайплайны из SQL и Python узлов, визуализировать данные и обеспечивать воспроизводимость исследовательских цепочек.

## Компоненты системы

### Frontend (apps/web)

- **Технологии**: Next.js 14+, React, tldraw, ReactFlow
- **Основные функции**:
  - Канва для создания DAG (Directed Acyclic Graph)
  - Узлы: SQL, Python, визуализации
  - Реалтайм коллаборация через WebSocket
  - Управление досками (boards) и воркспейсами

### Backend (apps/realtime-server)

- **Технологии**: Fastify, y-websocket, Prisma, PostgreSQL
- **Основные функции**:
  - REST API для управления ресурсами
  - WebSocket для реалтайм синхронизации
  - Обработка выполнения узлов (runs)
  - Управление подключениями к БД
  - Аудит событий

### Landing (apps/landing)

- **Технологии**: Vite, React
- **Назначение**: Маркетинговая страница

## Пакеты (packages/)

### core-domain

Доменные схемы и типы данных:

- Типы узлов (NodeType)
- Схемы валидации
- Общие интерфейсы

### dag-executor

Исполнитель направленных ациклических графов:

- Разрешение зависимостей
- Планирование выполнения
- Обработка ошибок

### ui-kit

Переиспользуемые UI компоненты:

- Кнопки, формы, модальные окна
- Общие стили

### wasm-bridge

Мост для работы с WebAssembly:

- Выполнение Python кода
- Обработка данных

## База данных

### Основные сущности (Prisma Schema)

- **User** - пользователи системы
- **Workspace** - рабочие пространства
- **Board** - доски (канвы)
- **Node** - узлы на доске
- **Connection** - связи между узлами
- **Run** - выполнение узлов
- **DatabaseConnection** - подключения к БД
- **AuditEvent** - события аудита

## Реалтайм синхронизация

Используется y-websocket для синхронизации состояния канвы между клиентами:

- CRDT (Conflict-free Replicated Data Type)
- Автоматическое разрешение конфликтов
- Оптимистичные обновления

## Безопасность

- JWT токены для аутентификации
- Роли и права доступа (authorizationService)
- Валидация всех входных данных
- Prepared statements для SQL

## Производительность

- Кэширование запросов к БД
- Оптимизация WebSocket сообщений
- Ленивая загрузка компонентов
- Индексы БД для частых запросов
