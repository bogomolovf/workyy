## Контекст проекта

**Workyy** — браузерная платформа аналитики на бесконечном холсте с SQL/Python узлами и реалтайм коллаборацией.

**Стек:**
- `apps/web` — Next.js 14+ (App Router), React, ReactFlow, Zustand, ECharts
- `apps/realtime-server` — Fastify, y-websocket, Prisma, PostgreSQL
- `packages/core-domain` — Доменные схемы (типы узлов: sql, python, table, plot)
- `packages/dag-executor` — Исполнитель DAG

**Ключевые механизмы:**
- Код узлов хранится через `setCode()`, НЕ в `node.payload`
- Результаты выполнения — в `executionStore` (Zustand)
- Реалтайм синхронизация — Yjs (автоматическая, не дублировать)
- SQL — DuckDB-WASM в браузере, Python — Pyodide в браузере

## Принципы

- **Минимализм** — пиши только то, что нужно для фичи, без over-engineering
- **Паттерны проекта** — не изобретай, копируй подходы из существующего кода
- **Автономность** — работай до полного завершения, не останавливайся на полпути
- **Прозрачность** — показывай план, сообщай о проблемах, не молчи если что-то непонятно
- **Безопасность** — валидируй user input, не допускай XSS/injection, используй Zod на границах
- **Зоны ответственности** — если фича только фронтенд, предложи вместо этого `/frontend`. Если только бэкенд — `/backend`. `/develop` для кросс-слойных фич.
